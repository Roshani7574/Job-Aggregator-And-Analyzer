# Job Aggregator & Analyzer

## About the Project

I built this project to learn the basics of web scraping using Python. The program collects job listings from a website, extracts useful information such as job title, company name, and location, and stores the data in a CSV file.

It also allows users to search for jobs using a keyword and view only the matching results.

## Features

* Scrapes job listings from a website
* Extracts job title, company, and location
* Saves data to a CSV file
* Filters jobs based on user-entered keywords
* Processes over 100 job records automatically

## Technologies Used

* Python
* Requests
* BeautifulSoup4
* CSV Module
* Git & GitHub

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Run the program:

   python scraper.py

3. Enter a keyword when prompted.
